# Meta 自动化预填助手 v1.1.0

## 安装或替换

1. 解压此 ZIP 到一个固定文件夹。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 首次安装点“加载已解压的扩展程序”，选中解压后的文件夹。
4. 替换已有版本时，把 ZIP 中的全部文件覆盖到当前已加载的扩展文件夹，然后在 `chrome://extensions` 点扩展卡片上的重新加载图标。
5. 刷新 Meta Business Suite 收件匣页面。

## 配置文件导出

在插件面板的设置中点击“导出”，当前页面直接打开系统保存窗口；选择扩展文件夹中的 `meta-autofill-config.json` 并确认覆盖。浏览器不支持保存窗口时，会直接下载 JSON 文件，不再打开说明分页。

关键词回复中的按钮网址必须使用 HTTPS，且不能在网址中嵌入账号或密码。

## 语言识别

默认自动识别 Meta 页面语言。识别成功时不在面板常驻显示语言文字，只在浏览器右上角短暂提示；检测失败时才显示语言选择器，并回退使用简体中文。

插件面板采用新版卡片布局，字号已放大并使用原始图标。两个操作按钮始终同时显示；网址中识别到 `automation_template=comment_to_inbox_v2` 时高亮“消息回复评论”，识别到 `automation_template=keyword_automation` 时高亮“自定义关键词回复”。主设置页没有模板参数，或参数无法识别时，两个按钮都不高亮。内容脚本仅在 Meta 自动回复页面运行。

## 检查更新

打开 Meta 收件匣页面时会检查 GitHub 最新稳定 Release；最小化状态不会弹窗。官网发布版本高于当前安装版本时展示更新内容；版本一致时提示“当前已经是最新版本”；当前安装版本高于官网发布版本时提示“当前是内测版本”。

更新源：<https://github.com/bstbuku-ship-it/meta-autofill/releases/latest>

“前往 GitHub 更新”会打开发布页。解压版扩展需要用户下载新版 ZIP、覆盖当前扩展文件夹，并在 `chrome://extensions` 重新加载。

## 权限

扩展保留 `storage` 权限，并请求 `https://api.github.com/*` 以读取公开 Release 信息。若 GitHub 暂时不可连接，插件照常使用，自动检查不会打断操作。填入成功后，浏览器右上角会显示 10 秒气泡，提醒检查内容、按需补充变量名再保存；版本检查与语言检测气泡各显示 2 秒，并优先显示版本结果。进度日志默认隐藏，只在出错时显示。
