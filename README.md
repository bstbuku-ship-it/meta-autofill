# Meta-自动化预填助手

Meta-自动化预填助手是一款用于 Meta Business Suite 消息/评论回复场景的 Chrome 浏览器扩展，帮助用户快速预填常用的名称、关键词、回复内容以及按钮信息。

## 功能说明

### 1\. 消息回复评论

用于设置评论回复相关的预填内容。

可配置：

* 名称
* 使用渠道

  * Messenger
  * Instagram
* 关键词
* 回复消息

插件会根据当前 Meta 页面中的对应输入区域进行自动填充。

### 2\. 自定义关键词回复

用于设置关键词触发后的回复内容。

可配置：

* 名称
* 使用渠道

  * Messenger
  * Instagram
* 关键词
* 回复消息
* 按钮文字
* 按钮链接

按钮链接可以使用 Messenger 链接，例如：

`https://m.me/你的账号`

3\. 多语言
默认自动识别页面语言
---

插件支持：

* 简体中文
* 繁体中文
* English


### 4\. 本地保存

插件的配置会保存在当前浏览器的 Chrome 本地存储中。

这意味着：

* 当前浏览器修改后的配置不会修改 GitHub 中的源文件。
* 不同浏览器之间不会自动同步这些配置。
* 清除浏览器扩展数据后，本地保存的配置可能会丢失。
* 插件源代码中的默认配置与浏览器当前保存的配置是两个不同层级。

### 5\. 默认配置文件

插件安装包中包含：

`meta-autofill-config.json`

这个文件是插件的默认配置源。

以后修改默认配置时，可以直接修改这个 JSON 文件，而不需要到 JavaScript 文件中重复修改同样的内容。

如果浏览器中已经保存过自己的配置，修改源文件不会自动覆盖浏览器中的本地配置。

需要重新使用源文件中的默认配置时，可以使用插件中的“恢复默认”功能。

### 6\. 导入与导出

插件支持配置导入和导出。

导出的配置文件可以用于：

* 备份当前配置
* 在其他浏览器中重新配置
* 保存某一套回复模板

导入配置时，插件会进行基本的数据格式和内容长度检查。

## 使用注意事项

### 1\. 仅用于 Meta Business Suite

插件的自动操作页面范围已经限制在：

`https://business.facebook.com/latest/inbox/\\\*`

因此插件并不是针对整个 Facebook 网站进行操作。

### 2\. Meta 页面发生变化时

插件依赖 Meta Business Suite 当前页面的 DOM 结构来定位输入框。

如果 Meta 后续修改页面结构、按钮文字或输入框布局，可能出现：

* 找不到输入框
* 找不到按钮
* 自动填充失败
* 某些功能正常、某些功能失效

这种情况通常不是配置文件的问题，而是 Meta 页面结构发生变化。

### 3\. 回复内容请自行确认

自动填充完成后，建议在发送之前检查：

* 收件人/评论对象
* 回复内容
* Messenger 或 Instagram 渠道
* 关键词
* 按钮文字
* 按钮链接

插件主要负责预填和辅助操作，不应在未经确认的情况下依赖自动填充结果直接发送重要信息。

### 4\. Messenger 链接

如果使用 Messenger 按钮，请确认：

`buttonUrl`

填写的是你自己的有效 Messenger 链接。

例如：

`https://m.me/你的账号`

不要把不属于自己的账号链接放入默认配置。

### 5\. 不要把敏感信息写入配置文件

不要在：

* `meta-autofill-config.json`
* 导出的配置文件
* GitHub 仓库

中保存：

* Facebook 密码
* Google 密码
* 浏览器 Cookie
* Access Token
* API Key
* 私钥
* 其他账号认证信息

本插件本身不需要读取 Facebook 密码或浏览器 Cookie 才能完成预填功能。



## 常见问题

### 为什么修改了 JSON，浏览器里的内容没有自动变化？

因为浏览器已经保存了自己的本地配置。

`meta-autofill-config.json` 是默认配置源，不会强制覆盖用户已经保存的本地设置。

可以使用“恢复默认”重新读取当前版本的默认配置。

### 为什么 Meta 页面突然不能自动填写了？

首先确认：

1. 当前页面是否为 Meta Business Suite Inbox。
2. 页面是否已经完全加载。
3. Meta 是否最近修改了页面布局。
4. 插件是否仍然正常启用。

如果页面结构发生变化，需要更新插件的页面定位逻辑。

### 插件会保存 Facebook 密码吗？

不会。

插件的正常功能不需要读取或保存 Facebook 密码、浏览器 Cookie 等登录凭证。
